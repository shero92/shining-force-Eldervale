# Eldervale — Unofficial Shining Force II Fan Project

This development branch is an **experimental, non-commercial** fan-project built on the Shining Force II disassembly. It is not affiliated with or endorsed by the game's rightsholders.

## Creative direction
- Setting: an isolated coastal island of ruins, flying dragons, ancient dragon remains and living monsters.
- Protagonist: approximately 21-year-old human swordsman raised on the island among monsters.
- Adoptive father: a kind, ancient nonhuman sage carrying an amber lantern staff.
- Setting history: multiple layers — primordial creatures older than known civilizations, ruins potentially connected with the Ancients, and creatures from other dimensions.
- Core hook: a storm washes Lemon's weathered sword ashore. Touching it causes a vision of a lone warrior, fire, a dark gateway and the warning: "The seal is weakening... Find the heirs of the power..."
- Character identities and origin mysteries are deliberately unresolved.

## Prologue target
Reach the sword within **10–15 minutes**. The first full tactical battle features strange unknown creatures emerging from coastal ruins, not ordinary island wildlife.

## Technical approach
1. Study existing event, map, battle and dialogue structures in `disasm/`.
2. Create new isolated assets and patches on feature branches.
3. Preserve the standard build branch until changes are reviewed.
4. Verify every ROM/build modification in a local environment supplied with a legitimately obtained original US ROM (not committed to this repository).
5. Avoid copying or distributing copyrighted original game assets separately.
6. Honor the parent project's **CC BY-NC 4.0** terms; non-commercial use only.

See `eldervale/PROLOGUE.md` for story and battle milestones.
