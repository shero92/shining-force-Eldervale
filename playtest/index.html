⚔️ Shining Force — Browser Playtest

Play a legally obtained Sega Genesis / Mega Drive ROM locally in your browser. No game ROM is bundled or uploaded to a server by this page.


Select a ROM file to begin.

How to test

Open this page through GitHub Pages or another HTTPS web host, choose your own ROM, and press Start. The emulator may load additional code from the EmulatorJS CDN; an internet connection is required for the first load. Keyboard/gamepad mappings are available in the emulator's settings.

This is a playtest launcher, not a modified game build. For gameplay changes, edit and rebuild the disassembly using the tools provided by this repository, then select the rebuilt ROM here.
